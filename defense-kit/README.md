- 固定真实子集结果：基线 accuracy 50.0%、recall 100.0%；SmallCNN accuracy 81.3%、precision 89.2%、recall 71.3%，FN=43。

## 复现与使用

实验复现命令、样本范围和指标解释统一以仓库根目录 `README.md` 与 `report.md` 为准。原始 40,000 张图片、`runs/`、文档/PPT 的排版验收中间文件均不进入 Git；本目录只提交可直接使用的最终答辩文档。

## 与学生学习教练的关系

`skills/student-learning-coach` 负责学习过程辅导，明确不写讲稿/答案、不伪造证据。本目录是额外的答辩准备包：保留教练的证据诚实原则，同时提供可朗读文本与追问答法。
